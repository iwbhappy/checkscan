# CheckScan

Flutter-приложение для локального учёта расходов по QR фискальных чеков Казахстана.
Основная платформа — Android 24+. Интерфейс на русском, Material 3, светлая и
тёмная темы. Исходное задание: [TZ.md](TZ.md).

## Что работает

- Сканирование камерой, фонарик, галерея и ручная вставка ссылки. Рекламный QR
  SMALL игнорируется. Для сложных фото применяются ограниченные по памяти
  кропы, масштабирование, grayscale и порог в отдельном isolate.
- Реальный JSON API `consumer.oofd.kz`, сменяемые провайдеры ОФД, безопасные
  редиректы и HTTPS с точечным HTTP fallback. QR сохраняется до запроса;
  повторный скан не создаёт дубль.
- Ручной ввод покупки без QR («Ввести вручную» на экране скана, в истории и
  в диалоге неподдерживаемого QR): магазин, дата, товары с количеством, ценой
  и категорией (подсказывается по правилам).
- Локальная Drift/SQLite-база: история, поиск по магазину/товару, фильтры,
  редактор загруженного чека, категории позиций, заметки, удаление с отменой.
- 16 категорий, встроенный словарь и пользовательские правила по штрихкоду,
  точному названию либо ключевому слову.
- Статистика по периодам, категориям, дням/неделям/месяцам, топ-10 магазинов
  и товаров, сравнение с предыдущим периодом, переходы в историю.
- Два CSV с BOM и `;` для Excel; JSON-бэкап с транзакционным слиянием без
  дублей. Системный обмен файлами, импорт через системный выбор документа.
- Сохранение темы и вида валюты (`₸`/`KZT`), очистка с двумя подтверждениями.
- Debug-экран исходного QR/ответа, доступный только в debug-сборке.

## Запуск и сборка

Проверенная среда: Flutter **3.44.8 stable**, встроенный Dart **3.12.2**,
Android SDK 36, Java 21. Используйте Dart из того же Flutter SDK: другая
версия `dart` в PATH может давать несовместимые диагностики.

```powershell
cd C:\PROJECTS\checkscan
flutter pub get
flutter run
```

Сгенерированные Drift/локализационные файлы включены в проект. После изменения
таблиц или ARB:

```powershell
dart run build_runner build
flutter gen-l10n
```

Полная проверка в PowerShell (скрипт сам выбирает встроенный Flutter Dart):

```powershell
.\tool\check.ps1
flutter build apk --release
```

Для release используйте команду без `--no-pub`: Flutter 3.44 обновляет список
нативных плагинов для production. Иначе после integration-теста может остаться
регистрация dev-плагина `integration_test`, отсутствующего в release.

APK: `build/app/outputs/flutter-apk/app-release.apk`. Для локальной установки:

```powershell
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

Release APK подписывается тестовым debug-ключом. Для публикации потребуется
собственный signing config; публикация в магазины не выполнялась.

Для iOS нужен macOS/Xcode и CocoaPods:

```sh
flutter pub get
cd ios && pod install && cd ..
flutter build ios --no-codesign
```

Нативная iOS-сборка на этой Windows-машине не проверена.

## Проверки

```powershell
flutter analyze
flutter test --coverage
python tool/check_coverage.py
flutter test integration_test/scan_pipeline_test.dart -d emulator-5554
```

Unit/DAO/widget-тесты и CI не используют реальную сеть. Device integration
использует настоящий `MobileScannerController.analyzeImage` и фотографию из
ТЗ; ответ ОФД заменён сохранённым реальным JSON. Этот сценарий успешно пройден
на Android-эмуляторе. Скрипт покрытия требует ≥80% строк domain/core/парсеров.

Последний полный прогон: `flutter analyze` — 0 замечаний, **98 тестов прошли**,
покрытие domain/core/парсеров — **93,9%** (383 из 408 строк). Native smoke
прошёл также после отключения диагностического транспорта ML Kit. Отдельно
на Android проверен живой HTTPS-запрос к ОФД: четыре позиции, итог 2 002 ₸.
Release APK успешно собран и установлен на эмулятор. Через интерфейс проверены
загрузка реального чека, отклонение дубликата, сохранение истории после
принудительного закрытия без сети и совпадение итога статистики с историей.

Для ручной проверки: [docs/MANUAL_QA.md](docs/MANUAL_QA.md). Скорость живой
камеры, блики и поведение на физических устройствах требуют отдельного прогона;
эмулятор не подтверждает нормативы 1–3 секунды на среднем телефоне.

## ОФД и реальные данные

Исследована одна реальная фотография и один чек. API действительно вернул четыре
позиции 299/435/489/779 ₸ и итог 2 002 ₸. НДС в API **276,14 ₸**, скидка **0**,
время **15:32:59** — они отличаются от бумажного примера в ТЗ. Приложение
не подменяет ответ значениями из задания. UTC+5 для времени API без зоны —
явно зафиксированное допущение ТЗ; к QR не добавляется выдуманный двухчасовой сдвиг.

Подробная схема, источники, SHA-256 и расхождения:
[docs/OFD_FORMAT.md](docs/OFD_FORMAT.md). Повторить реальное исследование:

```powershell
python -X utf8 tool/research_ofd.py --output build/ofd-research
```

Исследовательский скрипт обращается к сети; обычные тесты его не запускают.

У сервера обнаружена неполная цепочка TLS-сертификатов. Проверенный официальный
промежуточный CA включён в приложение только для `consumer.oofd.kz`; проверки
HTTPS сохранены. Причина, источники и срок действия сертификата:
[docs/OFD_TLS.md](docs/OFD_TLS.md).

## Ограничения v1

- Подтверждён Казахтелеком/OOFD и формат одного реального чека. Для иных ОФД,
  возвратов и иных форматов нужны реальные фикстуры и новый провайдер/парсер.
- `pending` повторяется по расписанию 1/5/30 минут при активном приложении,
  при запуске/возврате и по ручному обновлению истории. Нет фонового Android
  сервиса или обещания мгновенного повтора при смене сети в закрытом приложении.
- Незагруженный чек сохраняет QR-сумму; редактор открывается после загрузки
  позиций. Ошибка парсинга остаётся видимой и допускает ручной повтор.
- Статистика включает черновики. Остаток между суммой позиций и итогом
  относится к категории чека; отрицательные корректировки показаны списком
  без вводящей в заблуждение круговой диаграммы.
- Суммы хранятся в KZT; настройка валюты меняет обозначение, без конвертации.
- Приём внешнего share-intent оставлен как опциональный пункт ТЗ. OCR, сервер,
  аккаунты, облачная синхронизация и публикация в сторах не реализованы.

## Структура

```text
lib/app/                  router, тема, Riverpod, локализация и общие виджеты
lib/core/                 деньги, даты, QR, валидация, ошибки
lib/domain/models/        ParsedReceipt, ParsedItem, QrReceipt
lib/data/db/              Drift schema v1 и DAO
lib/data/ofd/             registry, провайдер, реальный JSON-парсер
lib/data/repositories/    чеки, категории, статистика, бэкапы
lib/features/             scan, receipts, stats, categories, settings
lib/l10n/                 русские ARB и generated localizations
assets/                   словарь правил и исходник иконки
test/fixtures/            реальный QR, фото, ответы, источники и provenance
integration_test/         native photo → mock OFD → SQLite
tool/                     проверки и воспроизводимое исследование
docs/                     формат ОФД, решения и ручное QA
```

Архитектурные решения и семантика сумм/дат:
[docs/DECISIONS.md](docs/DECISIONS.md).
