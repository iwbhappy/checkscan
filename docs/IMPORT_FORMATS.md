# Импорт чеков, версия 1.1

## Поддержка

| Источник | Обработка |
| --- | --- |
| QR Казахтелеком/OOFD | Существующий провайдер, загрузка JSON и защита от дубликатов |
| Фото с читаемым поддерживаемым QR | Оригинал, затем ограниченные по памяти варианты изображения |
| Фото без QR или с QR другого ОФД | Локальный OCR и обязательный экран проверки |
| PDF с текстовым слоем | Извлечение текста, поиск поддерживаемой QR-ссылки, проверка данных |
| PDF без текстового слоя | Отрисовка выбранной страницы, QR, затем OCR |
| Многостраничный PDF | Пользователь выбирает страницу; одна страница сохраняется как один чек |
| Возврат | Явный переключатель в редакторе; сумма и позиции уменьшают расходы |
| Android «Поделиться» | Один файл image/*, application/pdf или текстовая ссылка через ACTION_SEND |

Для фото и PDF нет автоматического сохранения результата OCR. Неизвестные поля
остаются пустыми. Если дата не распознана, редактор явно сообщает о подставленном
текущем времени. Строка без явного количества предлагается как одна позиция с
наблюдаемой суммой и подсказкой проверить количество/цену. Если товары отсутствуют,
можно подтвердить только общий итог. Различие суммы позиций и итога сохраняет
`needsReview`. Изменение только категории или заметки больше не пересчитывает итог.

Возвраты из неизвестных кодов операций API OOFD по-прежнему не выдаются за
поддержанные: для них нужны реальные ответы и отдельное сопоставление кодов.
Возврат через фото/PDF или ручной ввод подтверждается пользователем.

## Локальная обработка

Android: Tesseract4Android **4.9.0**, отдельный последовательный executor,
LSTM-модели `rus+kaz+eng`, PSM_SINGLE_BLOCK. Модели включены в приложение и
копируются в private application support directory; сеть при OCR не используется.
Конфигурация Gradle разрешает группу Tesseract4Android из JitPack только на этапе сборки.

iOS: системный Vision; русский OCR требует поддерживаемой системой модели
(проверка доступности во время выполнения, обычно iOS 16+). Казахский используется
только если система сообщает о его поддержке. Нативная iOS-сборка и качество
казахского текста на iPhone на Windows не проверены. iOS Share Extension не добавлен.

PDF: `pdfrx 2.2.24` / PDFium, локальный файл. Размер входного файла до 32 МБ,
фото до 16 Мп, отрисованная страница и изображение OCR ограничены 6 Мп,
предобработка QR ограничена 8 Мп. В PDF допускается до 100 страниц.
После восьми секунд поиска QR в фото новые варианты предобработки не запускаются:
текущий этап завершается и при отсутствии QR начинается распознавание текста.
Форматы фото для текстового распознавания: JPEG/PNG/WebP, поддерживаемые `image`.
Для HEIC системный QR-декодер может прочитать оригинал, но OCR-предобработка
потребует поддерживаемого формата; выбор фото через галерею может конвертировать его.

Отмена прекращает дальнейшие этапы и переходы интерфейса. Уже выполняющийся
нативный OCR завершается в worker; временные файлы удаляются после завершения.
Фото и распознанный текст не передаются облачному сервису. Только подходящий QR
может вызвать существующий запрос к ОФД. Камера при импорте приостанавливается.

## Идентичность и резервные копии

Импорт: `manual:import:<sha256 файла>`. Для PDF хэш включает номер страницы.
Повторный импорт того же файла/страницы открывает существующий чек. Это не
устраняет дубли между разными фотографиями одного бумажного чека или между
фотографией и QR-импортом.

Возврат: `manual:return:...`, для документа — `manual:return:import:<sha256>`.
Цены и количества положительные, суммы позиций и итог неположительные.
Редактор показывает положительные значения полей и сохраняет знак операции.
Экспорт с возвратами имеет версию **2**; без возвратов остаётся версия **1**.
Импорт принимает обе версии. Схема SQLite остаётся v1, существующая история
не переписывается. Старые приложения v1 не импортируют резервные копии v2.

## Проверки

- `flutter analyze`
- `flutter test --coverage` и `python tool/check_coverage.py`
- `flutter test integration_test/document_import_test.dart -d emulator-5554`
- `flutter test integration_test/scan_pipeline_test.dart -d emulator-5554`
- `flutter test tool/render_previews.dart` → `build/previews/*.png`
- `flutter build apk --release --split-per-abi`
- `python tool/check_android_manifest.py`

PDF в `test/fixtures/import/receipt_text.pdf` и изображение, создаваемое
integration-тестом OCR, синтетические. Они проверяют нативные движки и точное
извлечение суммы, но не доказывают качество OCR на выцветших/мятых реальных чеках.
Реальный корпус пока ограничен исходным чеком SMALL/OOFD.
