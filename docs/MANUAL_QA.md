## Камера и фото

- [ ] Холодный старт до готовой камеры ≤ 2 с; измерить на среднем устройстве.
- [ ] Живой QR распознаётся ≤ 1 с, ОФД-чек появляется ≤ 3 с при нормальной сети.
- [ ] Запрет камеры: понятный экран, переход в системные настройки, галерея/URL доступны.
- [ ] Возврат из настроек, сворачивание приложения, выключение экрана, повторный вход на вкладку: камера запускается/останавливается без утечки.
- [ ] Фонарик включается и выключается; устройство без вспышки не падает.
- [ ] Реальное `test/fixtures/photos/small_2026_10_07.jpg`: найден нижний фискальный QR; рекламный SMALL игнорируется.
- [ ] Фото с бликом, мятый чек, наклон, тусклый свет, маленький и большой QR.
- [ ] Фото без QR, несколько рекламных QR, несколько настоящих QR: подсказка или нижний допустимый код.
- [ ] Большой снимок не исчерпывает память; поворот по EXIF обработан.
- [ ] Отмена системного выбора фото возвращает к сканированию.
- [ ] Неизвестный домен отображается до перехода; автоматической загрузки с него нет.

## Сохранение и повторные попытки

- [ ] Во время загрузки закрыть приложение: сохранён QR-черновик с суммой/временем.
- [ ] Режим полёта: `pending`, после восстановления сети повторная загрузка.
- [ ] Повторы через 1, 5, 30 минут при открытом приложении; повтор при запуске/возврате.
- [ ] 404: чек остаётся черновиком; повреждённый ответ: статус ошибки с повтором.
- [ ] Два быстрых сканирования одного QR дают одну запись и переход к существующему чеку.
- [ ] Варианты `&amp;`, ведущие нули РНМ и другой параметр времени не создают дубль.
- [ ] Сохранённая история доступна без сети после полного перезапуска.
- [ ] Удаление/редактирование во время сетевого запроса не воскрешает/не перетирает чек.

## История и редактор

- [ ] Группировка сегодня/вчера/дата; время одинаково при смене системного часового пояса.
- [ ] У pending отображается время QR без выдуманного смещения.
- [ ] Поиск по русскому названию товара/магазина независимо от регистра.
- [ ] Фильтры периода, магазина, категории, минимума и максимума работают совместно.
- [ ] Редактирование магазина не меняет другие чеки того же продавца.
- [ ] Дата, заметка, категория чека и позиции сохраняются.
- [ ] Добавление/удаление/правка позиции пересчитывает сумму, устанавливает `edited`, оставляет исходный dedupKey.
- [ ] Весовой товар с количеством 0,534: сумма в целых тиынах и ожидаемое округление.
- [ ] 50+ позиций: список плавно прокручивается, клавиатура не закрывает поля.
- [ ] Свайп удаления и Undo восстанавливают позиции/категории/суммы.
- [ ] Предупреждение `needsReview` не скрывает сохранённые данные.
- [ ] Открытие ОФД запускает внешний браузер.

## Категории, статистика, перенос данных

- [ ] Пользовательское правило имеет приоритет над встроенным; штрихкод точнее имени.
- [ ] Создание/изменение/удаление своих категорий, защищённые встроенные категории.
- [ ] Удаление категории переводит связанные данные в «Прочее».
- [ ] Сумма категорий/временных столбцов совпадает с суммой чеков в периоде, включая pending и расхождения позиций.
- [ ] Неделя/месяц/год/произвольный период, сравнение и переход предыдущий/следующий.
- [ ] Переход с категории/магазина в историю устанавливает фильтр.
- [ ] CSV в Excel: кириллица, BOM, `;`, денежные дроби, кавычки и переносы строк.
- [ ] JSON round-trip на чистой БД и повторный импорт без дублей, перенос своих категорий/правил.
- [ ] Повреждённый JSON не изменяет БД частично.
- [ ] Тема и отображение валюты сохраняются после перезапуска.
- [ ] Полная очистка требует двух подтверждений и удаляет пользовательские правила/категории.

## Доступность и ограничения

- [ ] Светлая/тёмная тема, системный шрифт 200%, небольшой экран и альбомная ориентация.
- [ ] TalkBack: названия кнопок камеры, удаления, диаграмм и навигации понятны.
- [ ] Проверить контраст текста/состояний, доступность действий без распознавания цвета.
- [ ] Чек возврата: пока не подтверждён реальной фикстурой, неизвестный operationType должен дать явную ошибку, а не расход.
- [ ] На macOS: `flutter build ios --no-codesign`, затем камера/галерея/ATS на физическом iPhone.
